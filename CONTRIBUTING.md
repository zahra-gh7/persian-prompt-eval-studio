# Contributing to Persian Prompt Evaluation Studio

Thank you for your interest in contributing to Persian Prompt Evaluation Studio. This repository is designed as a public portfolio project for prompt evaluation and Persian NLP experimentation.

## How to contribute

- Fork the repository and create a feature branch.
- Open a clear pull request describing the change.
- Keep changes small and focused.
- Write clean Python code and follow existing style patterns.

## Reporting issues

- Use GitHub Issues to report bugs, broken links, or usability problems.
- Include steps to reproduce the issue and expected behavior.
- Add a screenshot or sample dataset when relevant.

## Development guidelines

- Keep the Streamlit UI intuitive and documentation up to date.
- Avoid committing API keys, secrets, or local machine artifacts.
- Use the `data/sample_questions.csv` sample file for dataset examples.
